================================================================================
v13.6 - Osnovne ispravke
================================================================================

1. [VISOKO] JMBG validacija
   Problem: Godina je bila hardkodirana na 2000.
   Resenje: Ekstrahuje se 3-cifrena godina iz JMBG (poz. 4-6), probaju se
            oba raspona (1000-1999 i 2000-2999).

2. [VISOKO] Indeksiranje nakon brisanja
   Problem: int(sel[0]) - 1 je davalo pogrešan indeks nakon brisanja reda.
   Resenje: Zamena sa self.tree.index(sel[0]) - uvek tačan indeks.

3. [SREDNJI] Datum OD/DO
   Problem: DatumOd i DatumDo su uvek bili isti.
   Resenje: Dva posebna polja "Datum OD" i "Datum DO" sa kalendar dugmadima.

4. [SREDNJI] File lock
   Problem: Nije bilo zaštite od korupcije JSON fajla.
   Resenje: Dodat fcntl.flock() za atomicno čuvanje.

================================================================================
v13.7 - Cross-platform i validacija
================================================================================

5. [VISOKO] fcntl na Windows
   Problem: fcntl je Unix/Mac modul, pada na Windows.
   Resenje: platform check - fcntl na Unix, atomic write na Windows.

6. [VISOKO] assert iznos > 0
   Problem: assert se ne izvršava sa -O flagom.
   Resenje: Zamena sa if iznos <= 0: raise ValueError.

7. [SREDNJI] subprocess.run bez check=True
   Problem: Ako pip install padne, sledeća linija crash-uje.
   Resenje: Dodato check=True.

8. [SREDNJI] Provera datum_do >= datum_od
   Problem: Korisnik može uneti kraji datum pre početnog.
   Resenje: Dodata provera sa porukom o grešci.

9. [SREDNJI] Tabela prikazuje oba datuma
   Problem: Tabela je prikazivala samo jedan datum.
   Resenje: Sada prikazuje "DD/MM/YYYY - DD/MM/YYYY".

10. [NIZAK] XSD validacija iz memorije
    Problem: XML fajl čitan dvaput sa diska.
    Resenje: Validacija direktno iz root objekta.

11. [NIZAK] strip() umesto replace(" ", "")
    Problem: Brisanje samo space, ne sve whitespace.
    Resenje: Koristi se .strip().

12. [NIZAK] Error handling za korumpirani JSON
    Problem: Ako je JSON oštećen, aplikacija pada.
    Resenje: try/except za JSONDecodeError i ValueError.

13. [VISOKO] EBS identifikator
    Problem: XSD dozvoljava EBS (value="5"), kod nije imao.

14. [VISOKO] Broj poljoprivrednog gazdinstva
    Problem: XSD ima BrojPoljoprivrednogGazdinstva, kod nije.
    Resenje: Dodato polje (opciono).

15. [VISOKO] Naziv poljoprivrednog gazdinstva
    Problem: XSD ima NazivPoljoprivrednogGazdinstva, kod nije.
    Resenje: Dodato polje (opciono).

16. [SREDNJI] Email osobe
    Problem: XSD ima ElektronskaAdresa za osobu, kod nije.
    Resenje: Dodato polje (opciono).

17. [SREDNJI] Validacija strukture JSON fajla
    Problem: Ako JSON nema "ljudi" ili "podnosioc", aplikacija pada.
    Resenje: Provera tipa i postojanja ključeva.
