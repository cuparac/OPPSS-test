4. ISTORIJA UNAPREĐENJA (DETALJNO)

v13.5 - Originalna verzija

- JMBG validacija (osnovna)

- JMBG: ekstrahuje godinu iz JMBG-a, probava oba raspona
- tree.index() umesto int(sel[0]) - 1

- assert → if za iznos
- Provera datum_do >= datum_od

- XSD validacija iz memorije
- strip() umesto replace(" ", "")
- Error handling za korumpirani JSON

v14.0 - Standalone verzije

================================================================================
9. REŠENI PROBLEMI
================================================================================

1. JMBG godina hardkodirana na 2000 → Ekstrahuje se iz JMBG-a
2. int(sel[0]) - 1 → tree.index(sel[0])
3. fcntl na Windows → atomic write
4. assert iznos > 0 → if iznos <= 0
5. externally-managed-environment → apt install python3-lxml
6. godina property → ispravan redosled inicijalizacije
