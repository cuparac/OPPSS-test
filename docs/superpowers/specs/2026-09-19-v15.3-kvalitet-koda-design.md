## 1. Arhitektura

### Modularna struktura

```
opps_generator_gui_v15.3.py   ← entry point (glavni fajl)
├── database.py               ← Database + migracija JSON
├── validacije.py             ← JMBG, EBS, datum, XSD validacije
├── xml_generator.py          ← generisanje XML + HTML izveštaja
└── gui.py                    ← App, DatumEntry, Kalendar, Prozori
```

### Tok podataka

1. `database.py` — sve SQLite operacije (CRUD, pretraga, statistika, CSV import/export)
2. `validacije.py` — čisti funkcije (JMBG, EBS, konvertuj_datum, get_xsd_schema)
3. `xml_generator.py` — generisanje XML i HTML izveštaja
4. `gui.py` — sve GUI komponente (App, DatumEntry, Kalendar, Prozori)
5. `opps_generator_gui_v15.3.py` — entry point koji pokreće App

### Zašto moduli?

- **Testabilnost:** Database i validacije se mogu testirati bez GUI-a
- **Održavanost:** Svaki modul ima jasnu odgovornost
- **Type hintovi:** Lakše se dodaju kada su funkcije razdvojene
- **Logging:** Centralizovani logging modul

## 2. Type hintovi

### Pravila

- Sve javne funkcije i metode imaju type hintove
- Koristi se `typing` modul za kompleksne tipove (Dict, List, Optional, Tuple)
- Return tipovi su obavezni
- `Any` se koristi samo kada je neizbežnji (tkinter objekti)

### Primer

```python
def validan_jmbg(jmbg: str) -> bool:
    """Proverava ispravnost JMBG-a.
    
    Args:
        jmbg: 13-cifreni matični broj
        
    Returns:
        True ako je JMBG ispravan, False inače
    """
```

```python
class Database:
    def __init__(self, godina: str) -> None:
        """Inicijalizuje Database.
        
        Args:
            godina: Godina kao string (npr. "2026")
        """
```

## 4. Logging

### Pravila

- `print()` se zamenjuje sa `logging.info()`, `logging.error()`, `logging.warning()`
- Konfiguracija logginga na početku aplikacije (u entry point-u)
- Log fajl: `opps_generator.log` u istom direktorijumu
- Format: `%(asctime)s - %(levelname)s - %(message)s`
- Nivoi: INFO za operacije, WARNING za upozorenja, ERROR za greške

### Primer

```python
import logging

logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s',
    handlers=[
        logging.FileHandler('opps_generator.log'),
        logging.StreamHandler()
    ]
)

logging.info("Aplikacija pokrenuta")
logging.error("Greška pri čitanju baze: %s", e)
```

## 5. Testovi (pytest)

### Struktura

```
tests/
├── conftest.py           ← zajednički fixtures (tmp db)
├── test_database.py      — CRUD, pretraga, statistika, CSV
├── test_validacije.py    — JMBG, EBS, datum, XSD
└── test_xml.py           — generisanje XML
```

### Coverage

- **Database:** kreiranje tabele, CRUD operacije, pretraga, statistika, CSV import/export
- **Validacije:** JMBG (ispravan, neispravan datum, neispravna kontrolna cifra), EBS, konvertuj_datum
- **XML:** generisanje validnog XML-a, XSD validacija

### Fixtures

```python
@pytest.fixture
def db(tmp_path):
    """Privremena baza za testove."""
    database = Database("2026")
    database.db_file = str(tmp_path / "test.db")
    database.kreiraj_tabele()
    yield database
    database.zatvori()
```
